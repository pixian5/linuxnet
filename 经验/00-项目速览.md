# 项目速览（给后续接手的人）

## 一句话

在 Ubuntu 上跑一条安装脚本，得到“按进程看流量 + 出站超限自动关机”的服务器。

## 代码地图

| 文件 | 作用 | 改它要注意 |
|---|---|---|
| `scripts/install_linuxnet_stack.sh` | 唯一入口，幂等安装 | 参数校验在最前面 `validate_inputs`；Picosnitch 用 2.x，**不要退回 1.x**（内核 6.14+ 上 BPF 编译必失败） |
| `templates/check-tx-shutdown.sh` | 核心判定，10 秒一次 | 状态文件格式改动要同时改 `traffic-guard-web.py` 的 `read_state` |
| `templates/send-shutdown-mail.sh` | 发信 | 参数是 `warning\|shutdown <used> <limit> [warn%]`；SQL 需同时兼容 1.x/2.x 两代 schema |
| `templates/traffic-guard-web.py` | 阈值面板 | `write_env_file` 必须保留未知键 |
| `tests/verify_traffic_guard.sh` | Shell 判定验证 | 新增判定分支要同步加场景 |

## 数据流

```
内核 tx_bytes → check-tx-shutdown.sh → 状态文件 → (预警/超限) → msmtp → 邮件
                     ↓                                    ↓
                traffic-guard-web.py                  poweroff
```

## 改代码前先想

1. 这个改动会不会影响“第二次部署”？（幂等）
2. 状态文件格式变了，Web 面板读得出来吗？
3. 关机路径改了吗？改了就必须用 `ACTION=none` 跑一遍验证。

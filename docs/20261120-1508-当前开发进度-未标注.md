### 2. 邮件通知改造为通用 SMTP

原实现只支持 Gmail 587/STARTTLS，硬编码 `tls_starttls on`。改用 189 邮箱 465 端口（隐式 TLS）会直接失败。

改动：

- 新增 `SMTP_STARTTLS` 配置项（`on` / `off`），留空时按端口自动推断：465 → `off`，其它 → `on`。
- 开关 `ENABLE_GMAIL_NOTIFY` 更名 `ENABLE_MAIL_NOTIFY`，旧名保留兼容。
- 示例文件 `gmail-notify.conf.example` 更名为 `mail-notify.conf.example`。
- 实际部署路径仍为 `/etc/traffic-guard/gmail-notify.conf`，避免破坏现有部署。

### 3. 修复密码含特殊字符导致配置无法解析

189 邮箱密码 `<SMTP_PASSWORD>` 含 `#` 和 `(` 和 `!`。原脚本直接 `SMTP_PASS=${SMTP_PASS}` 写入，被 `source` 时：

- `#` 被当作注释起始；
- `(` 触发 `syntax error near unexpected token '('`。

修复：写入时所有值用单引号包裹，内部单引号按 shell 规则转义为 `'\''`。

## 服务器实际配置（uw / ue 均已生效）

```bash
ENABLE_MAIL_NOTIFY=1
MAIL_FROM=<SMTP_ACCOUNT>
MAIL_TO=<SMTP_ACCOUNT>
SMTP_HOST=smtp.189.cn
SMTP_PORT=465
SMTP_STARTTLS=off
SMTP_USER=<SMTP_ACCOUNT>
```

## 端口选择说明

189 邮箱同时开放 465 和 587，两者都可达。选 465 是因为它用隐式 TLS，握手更简单，失败点更少；587 需要 STARTTLS 升级，多一步协商。
